`PCAModel` is an inductive anomaly model. It uses [scikit-learn's `PCA`](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html) to learn a low-dimensional representation from the training split, then assigns each validation or test row a higher-is-more-anomalous Euclidean reconstruction residual.

## Parameters

| parameter | required type | default | meaning |
| --- | --- | --- | --- |
| `n_components` | `int` from `1` to one less than the feature width | no default | Number of principal components retained for reconstruction. |
| `standardize_features` | `bool` | no default | Whether to fit `StandardScaler` on training features before PCA. |

PCA itself centers its input. With `standardize_features: true`, the benchmark additionally uses [scikit-learn's `StandardScaler`](https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.StandardScaler.html) to scale every feature using training-split statistics. The fitted scaler is then reused unchanged for validation and test rows.

```python
# import pca and standardscaler dependencies (documentation excerpt; keep synchronized)
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

# configure pca and optional train-fitted standardization (documentation excerpt; keep synchronized)
self.pca = PCA(n_components=self.n_components)
self.scaler = StandardScaler() if self.standardize_features else None
self.feature_width: int | None = None
```

## Fit

### 1. Fit PCA

The model optionally standardizes training features, then scikit-learn PCA centers the resulting matrix and retains `n_components` principal directions. `n_components` must be less than the feature width, preventing full-dimensional reconstruction.

For the fitted training matrix $X$, PCA centers each feature to produce $X_c$ and computes its singular value decomposition:

$$
X_c = U \Sigma V^\mathsf{T}
$$

The first `n_components` rows of $V^\mathsf{T}$ are the retained directions used to project and reconstruct later rows.

```python
# 1. fit pca on train-only scaled features (documentation excerpt; keep synchronized)
self.pca.fit(self.fit_scale(features))
self.feature_width = feature_width
```

## Score

### 2. Reconstruction Residuals

For each later feature row $x$, the model applies the fitted scaling transformation, projects the transformed row into PCA space, reconstructs it as $\hat{x}$, and uses the Euclidean residual as its anomaly score:

$$
\mathrm{score}(x) = \lVert x - \hat{x} \rVert_2
$$

Here, $x$ is the scaled row. The model requires the same feature width used during fitting.

```python
# 2. scale, reconstruct, and score each feature row (documentation excerpt; keep synchronized)
scaled = self.scale(features)
reconstructed = self.pca.inverse_transform(self.pca.transform(scaled))
scores = tuple(
    math.dist(feature_row, reconstructed_row)
    for feature_row, reconstructed_row in zip(
        scaled, reconstructed, strict=True
    )
)
```

## Persisted State

Validated inductive runs persist the fitted PCA estimator, optional fitted scaler, feature width, and configured parameters. The logger is deliberately not serialized; loading attaches the logger of the current process.

### 3. Save

```python
# 3. persist fitted pca state without the process-specific logger (documentation excerpt; keep synchronized)
pickle.dump(
    {
        "n_components": self.n_components,
        "standardize_features": self.standardize_features,
        "feature_width": self.feature_width,
        "pca": self.pca,
        "scaler": self.scaler,
    },
    file,
)
```

### 4. Load

```python
# 4. restore fitted pca state with the current process logger (documentation excerpt; keep synchronized)
model = cls(
    logger=logger,
    n_components=payload["n_components"],
    standardize_features=payload["standardize_features"],
)
model.feature_width = payload["feature_width"]
model.pca = payload["pca"]
model.scaler = payload["scaler"]
```
