---
title: Event Metrics
description: Metrics for contiguous anomaly events.
---

Event metrics evaluate how many **events**, not timestamps, overlap. The evaluator converts anomaly scores to binary predictions once at the applied threshold and shares that vector with point and event metrics.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `labels` | `Sequence[int]` | $y_t$: `0` for normal, `1` for anomaly. |
| `predictions` | `Sequence[int]` | $\hat y_t$: `0` for normal, `1` for predicted anomaly. |

## Inputs

For each timestamp $t$, the benchmark requires a binary label $y_t \in \{0, 1\}$ and a finite anomaly score $s_t$. Given the selected threshold $\tau$, `evaluate_metrics()` predicts an anomaly when:

$$
\hat{y}_t = \begin{cases}
1 & \text{if } s_t \geq \tau \\
0 & \text{otherwise}
\end{cases}
$$

The evaluator applies the threshold once and shares the resulting vector with threshold-dependent metric families:

```python
predictions = tuple(int(score >= threshold) for score in scores)
```

## Events

An event is a maximal contiguous interval of positive timestamps. The ground-truth and predicted events are:

$$
\mathcal A=\{A_1,\ldots,A_N\}, \qquad A_i=[a_i,b_i],
$$

$$
\hat{\mathcal A}=\{\hat A_1,\ldots,\hat A_M\}, \qquad \hat A_j=[\hat a_j,\hat b_j].
$$

The shared `extract_intervals()` method constructs $\mathcal A$ from `labels` and $\hat{\mathcal A}$ from `predictions`. It extracts maximal positive runs: each interval includes both endpoints, indices start at zero, and adjacent positive timestamps form one event.

```python
# extract maximal contiguous positive intervals (documentation excerpt; keep synchronized)
result = []
start: int | None = None
for index, value in enumerate(values):
    if value and start is None:
        start = index
    elif not value and start is not None:
        result.append((start, index - 1))
        start = None
if start is not None:
    result.append((start, len(values) - 1))
return tuple(result)
```

```python
# 1. extract label and predicted intervals (documentation excerpt; keep synchronized)
label_intervals = extract_intervals(labels)
predicted_intervals = extract_intervals(predictions)
```

## Overlap

Events overlap when:

$$
A_i\cap\hat A_j\ne\varnothing
\quad\Longleftrightarrow\quad
a_i\le\hat b_j\;\text{and}\;\hat a_j\le b_i.
$$

One overlapping timestamp is sufficient; matching is not one-to-one.

```python
# 2. check whether two events share a timestamp (documentation excerpt; keep synchronized)
return first[0] <= second[1] and second[0] <= first[1]
```

## Event Precision

Each predicted event receives one hit if it overlaps **any** true event. Precision is the fraction of predicted events that hit:

$$
d(\hat A_j)=\mathbf1\big(\exists A_i:A_i\cap\hat A_j\ne\varnothing\big),
\qquad P_E=\frac{1}{M}\sum_{j=1}^{M}d(\hat A_j).
$$

```python
# 3. average hits across predicted events (documentation excerpt; keep synchronized)
return (
    sum(
        any(_events_overlap(predicted, label) for label in label_intervals)
        for predicted in predicted_intervals
    )
    / len(predicted_intervals)
    if predicted_intervals
    else 0.0
)
```

## Event Recall

Each true event receives one hit if **any** predicted event overlaps it. Recall is the fraction of true events detected:

$$
d(A_i)=\mathbf1\big(\exists\hat A_j:A_i\cap\hat A_j\ne\varnothing\big),
\qquad R_E=\frac{1}{N}\sum_{i=1}^{N}d(A_i).
$$

```python
# 4. average hits across true events (documentation excerpt; keep synchronized)
return (
    sum(
        any(_events_overlap(label, predicted) for predicted in predicted_intervals)
        for label in label_intervals
    )
    / len(label_intervals)
    if label_intervals
    else 0.0
)
```

## Event F1

Event F1 is the harmonic mean of event precision and event recall:

$$
F_{1,E}=\frac{2P_ER_E}{P_E+R_E}.
$$

Precision is `0.0` when there are no predicted events; recall is `0.0` when there are no labeled events. F1 is `0.0` when both components are zero.

```python
precision = event_precision(label_intervals, predicted_intervals)
recall = event_recall(label_intervals, predicted_intervals)
f1 = 2 * precision * recall / (precision + recall) if precision + recall else 0.0

return EventMetrics(precision=precision, recall=recall, f1=f1)
```
