---
title: Point Metrics
description: Pointwise anomaly-classification measures.
---

Point metrics evaluate every timestamp independently. The evaluator converts anomaly scores to binary predictions once at the applied threshold, then passes the same predictions to point and event metrics.

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `labels` | `Sequence[int]` | $y_t$: one label per timestamp; `0` for normal, `1` for anomaly. |
| `predictions` | `Sequence[int]` | $\hat y_t$: binary predictions at the applied threshold; `0` for normal, `1` for anomaly. |
| `logger` | `ComponentLogger` | Records the resulting point precision, recall, and F1. |

## Inputs

For each timestamp $t$, the benchmark requires a binary label $y_t \in \{0, 1\}$ and a finite anomaly score $s_t$. Given the selected threshold $\tau$, `evaluate_metrics()` predicts an anomaly when:

$$
\hat{y}_t = \begin{cases}
1 & \text{if } s_t \geq \tau \\
0 & \text{otherwise}
\end{cases}
$$

The evaluator applies the threshold once and shares the resulting vector with threshold-dependent metric families:

```python
predictions = tuple(int(score >= threshold) for score in scores)
```

The label and score sequences must have equal length, labels must be binary, and scores must be finite; the evaluator checks these before thresholding. The selector is calibrated on validation data and derives the test threshold without test labels; the effective threshold stays fixed during each evaluation. Model selection uses the resulting `metrics.point` rather than recalculating point metrics.

The implementation begins by counting true positives, false positives, and false negatives:

```python
def point_metrics(
    labels: Sequence[int], predictions: Sequence[int], logger: ComponentLogger
) -> PointMetrics:
    # 1. count confusion-matrix values (documentation excerpt; keep synchronized)
    true_positives = sum(
        label == 1 and prediction == 1 for label, prediction in zip(labels, predictions)
    )
    false_positives = sum(
        label == 0 and prediction == 1 for label, prediction in zip(labels, predictions)
    )
    false_negatives = sum(
        label == 1 and prediction == 0 for label, prediction in zip(labels, predictions)
    )
```

## Precision

Precision is the fraction of predicted anomalies that are true anomalies:

$$
\mathrm{precision} = \frac{TP}{TP + FP}
$$

It is `0.0` when the model predicts no anomalies.

```python
# 2. calculate precision (documentation excerpt; keep synchronized)
precision = (
    true_positives / (true_positives + false_positives)
    if true_positives + false_positives
    else 0.0
)
```

## Recall

Recall is the fraction of labeled anomalies that the model detects:

$$
\mathrm{recall} = \frac{TP}{TP + FN}
$$

It is `0.0` when the series contains no labeled anomalies.

```python
# 3. calculate recall (documentation excerpt; keep synchronized)
recall = (
    true_positives / (true_positives + false_negatives)
    if true_positives + false_negatives
    else 0.0
)
```

## F1

F1 is the harmonic mean of precision and recall:

$$
F_1 = \frac{2 \cdot \mathrm{precision} \cdot \mathrm{recall}}
{\mathrm{precision} + \mathrm{recall}}
$$

It is `0.0` when both precision and recall are zero.

```python
# 4. calculate F1 (documentation excerpt; keep synchronized)
f1 = 2 * precision * recall / (precision + recall) if precision + recall else 0.0
```
