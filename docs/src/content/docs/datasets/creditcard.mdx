## Schema

The raw schema has `timestamp`, feature columns `V1` through `V28` plus `Amount`, and binary `is_anomaly` labels. Refinement maps the features in declared order:

| Raw columns | Refined columns | Role |
| --- | --- | --- |
| `timestamp` | `timestamp` | Timestamp |
| `V1` through `V28` | `feature_0` through `feature_27` | Numeric features |
| `Amount` | `feature_28` | Numeric feature |
| `is_anomaly` | `label` | Binary anomaly label |

The manifest stores SHA-256 checksums for every raw and refined split. The loader verifies the refined checksum before a protocol receives the split.
