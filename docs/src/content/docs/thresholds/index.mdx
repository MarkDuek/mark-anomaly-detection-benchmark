---
title: Thresholds
description: Rules for converting anomaly scores into binary decisions.
---

Thresholds convert higher-is-more-anomalous scores into binary predictions. The experiment runner calibrates each selector from labeled validation scores, records its calibration state in the validated run artifact, then derives a test threshold without using test labels.

## Prediction Rule

For anomaly score $s_t$ and selected threshold $\tau$, the prediction at timestamp $t$ is:

$$
\hat{y}_t = \begin{cases}
1 & \text{if } s_t \geq \tau \\
0 & \text{otherwise}
\end{cases}
$$

The threshold affects point, event, affiliation, and prediction-based VUS metrics. Ranking metrics use the original scores directly and do not use a threshold.

## Lifecycle

1. A protocol produces validation scores.
2. The configured selector uses validation scores and labels to select $\tau$ and fit any required calibration state.
3. The experiment records $\tau$ and calibration state with the selected validation artifact.
4. A protocol produces test scores.
5. The selector derives an effective test threshold from its calibration state and the test scores, without using test labels.

## Available Selectors

| Selector | Objective | Tie rule |
| --- | --- | --- |
